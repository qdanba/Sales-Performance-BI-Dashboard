# Dashboard

This folder contains the Power BI report and screenshots of its pages.

## Main file
- `Sales-Performance-BI-Dashboard.pbix` – interactive Power BI report built using AdventureWorks2025 data.

## Report pages
| Page | Focus |
|---|---|
| 1. Sales Overview | Executive KPIs, sales trend, and revenue mix |
| 2. Product Performance | Category contribution and top-performing products |
| 3. Customer Analysis | Store vs. Individual customer mix and leading customers |
| 4. Territory Analysis | Sales by country and sales territory |

## Screenshots
The `Screenshots/` folder contains static previews of the four report pages. They let visitors review the report without opening Power BI Desktop.

## How to view
1. Download the `.pbix` file from this folder.
2. Open it using Microsoft Power BI Desktop.
3. If Power BI requests a data-source connection, update it to the SQL Server instance available on your computer. The original report was developed using a local SQL Server instance and AdventureWorks2025.

Use the PBIX for interactive filtering and drill-down; screenshots are previews only.
